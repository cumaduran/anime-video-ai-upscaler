# Anime Video Upscaler & Encoder

Bu Windows masaüstü uygulaması videoları kuyruğa eklemeyi, yapay zekâ ile iyileştirmeyi, kısa örnekleri karşılaştırmayı ve kodlamayı bir araya getirir. Bu sürüm geliştirme önizlemesidir; büyük işlemlerden önce kısa bir video üzerinde sonuçları kontrol edin.

Kullanım ayrıntıları için projenin kökündeki `README.tr.md` dosyasına bakın.
