# Geliştirme ve proje yapısı

Masaüstü kodu `app/anime_video_upscaler/`, yerel motor `engine/core/`, motor başlıkları `engine/include/`, komut satırı katmanı `engine/cli/` altındadır. Testler `tests/anime_video_upscaler/`, derleme araçları `scripts/` içindedir. Ayrıntılı klasör açıklaması `docs/project-structure.tr.md` dosyasındadır.

Python testlerini proje kökünde `.venv-anime\Scripts\python.exe -m pytest` ile çalıştırın. Yerel derleme ve taşınabilir paket hazırlama yönergeleri `docs/anime-upscaler.md` dosyasındadır.
